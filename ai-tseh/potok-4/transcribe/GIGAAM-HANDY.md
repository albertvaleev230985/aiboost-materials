# Инструкция для агента: GigaAM v3 под ключ (расшифровка записей + диктовка голосом Handy), замена Whisper

Ты агент (Codex) на компьютере пользователя. Задача: чтобы вся работа с русской речью на этом
компьютере шла через GigaAM v3 от Сбера, локально и быстро. Частей три:

1. **Расшифровка записей.** Команда `neovida-transcribe`: файл или ссылка превращается в текст
   с таймкодами. Ею ты сам пользуешься, когда тебя просят «расшифруй».
2. **Диктовка голосом.** Приложение Handy: человек зажал клавишу, сказал, отпустил, и текст
   появился там, где стоит курсор (в тебе, в Telegram, в почте, где угодно). Внутри та же GigaAM v3.
3. **Замена Whisper.** Всё, где на этом компьютере для русской речи по умолчанию стоял Whisper,
   переводишь на GigaAM v3.

Делай всё сам, по шагам, коротко сообщая, что происходит. Пользователь не программист: терминал
не открывает, файлы не раскладывает. От него нужно: «да» на твои запросы разрешений, три клика
в системных настройках (разрешения для Handy, без них macOS не даст работать никому) и одна
фраза голосом для проверки.

Как объяснить пользователю, зачем это (скажи в начале, своими словами, в три строки):

- Любой звук это сырьё. ИИ лучше всего работает с текстом, значит, сначала звук в текст.
- GigaAM v3 обучена на русской речи: сама ставит знаки препинания, пишет числа цифрами и молчит
  в тишине. Whisper на русском в шуме и паузах выдумывает фразы и повторяет куски.
- Всё работает на самом компьютере: звук никуда не уходит, подписок и лимитов нет.

**Эта инструкция для macOS.** Если система другая, часть 1 поставь по её инструкции (там есть
Windows), а про Handy честно скажи, что эта инструкция проверена только на Mac, и остановись.

## Перед началом: песочница и таймауты

- Шаги качают файлы из интернета и пишут в домашнюю папку и в «Программы». В песочнице Codex это
  закрыто, поэтому запускай их сразу с запросом разрешения (вне песочницы). Пользователь ответит «да».
- Большие таймауты: установка библиотек и скачивание моделей до 20 минут (`timeout_ms` 1200000).
- Каждую команду пиши целиком, с полными путями: переменные между командами не сохраняются.
- Ничего не удаляй без прямого «да» пользователя. Перед правкой любого чужого файла делай копию
  рядом с именем `<файл>.bak-ГГГГММДД`.

## Шаг 2. Диктовка голосом: Handy с GigaAM v3

### 2.1. Приложение

Нужна версия 0.10.0 или новее: в ней появилась GigaAM v3 E2E-RNN-T, лучший вариант для русской
диктовки. Если на шаге 0 версия уже 0.10.0 или выше, этот пункт пропусти.

Возьми адрес по чипу: `arm64` это `aarch64.dmg`, `x86_64` это `x64.dmg`. Пример для чипа M:

```bash
curl -fL -o ~/Downloads/Handy_0.10.0.dmg https://github.com/cjpais/Handy/releases/download/v0.10.0/Handy_0.10.0_aarch64.dmg
hdiutil attach ~/Downloads/Handy_0.10.0.dmg -nobrowse -readonly -mountpoint /tmp/handy-dmg
ls /tmp/handy-dmg
```

Если Handy уже стоял (старая версия): сначала закрой его и убери старую программу в Корзину,
настройки, история и выданные разрешения при этом остаются на месте (проверено на обновлении
с 0.9.6 до 0.10.0: шаг 2.3 тогда сводится к запуску, разрешения заново не спрашиваются). Старые
модели прежнего формата (папки `giga-am-v3-int8`, `parakeet-...-int8`) новая версия загрузить
уже не может: после проверки 2.5 назови их пользователю с размером и спроси, удалить ли.

```bash
osascript -e 'quit app "Handy"'; sleep 3; pgrep -x handy && pkill -x handy
mv /Applications/Handy.app ~/.Trash/"Handy-старый-$(date +%Y%m%d-%H%M%S).app"
```

Установка и проверка подписи:

```bash
cp -R /tmp/handy-dmg/Handy.app /Applications/
hdiutil detach /tmp/handy-dmg
spctl -a -vv /Applications/Handy.app
defaults read /Applications/Handy.app/Contents/Info.plist CFBundleShortVersionString
```

Успех: `accepted`, `source=Notarized Developer ID`, `origin=Developer ID Application: Christopher Pais (UWFLB4GC25)`,
версия `0.10.0`. Если подпись другая или `rejected`, удали скачанное, ничего не запускай и скажи
пользователю. Если GitHub не отдаёт файл (обрыв, таймаут), попроси пользователя включить VPN и повтори.

### 2.2. Модель GigaAM v3

Качаем заранее, чтобы пользователю не пришлось ничего выбирать и ждать в самом приложении.
Сначала в «Загрузки», после проверки суммы переносим в папку моделей Handy.

```bash
curl -fL -C - -o ~/Downloads/gigaam-v3-e2e-rnnt-Q8_0.gguf https://blob.handy.computer/handy-computer/gigaam-v3-e2e-rnnt-gguf/f719d70812344f4d0fb8c11c0887b190501a7465/gigaam-v3-e2e-rnnt-Q8_0.gguf
shasum -a 256 ~/Downloads/gigaam-v3-e2e-rnnt-Q8_0.gguf
```

Сумма должна быть ровно `78d63b47723b7f8d78c6113a6ef983b5a86e2a86f6c273e1f5cb6967b1c4467a`,
размер 273 724 832 байта. Если обрыв, запусти ту же команду ещё раз: докачает. Если первый адрес
не отвечает, возьми запасной (huggingface.co) с тем же именем файла. Сумма не сошлась: удали файл
и скачай заново, в Handy его не клади.

```bash
mkdir -p "$HOME/Library/Application Support/com.pais.handy/models"
mv ~/Downloads/gigaam-v3-e2e-rnnt-Q8_0.gguf "$HOME/Library/Application Support/com.pais.handy/models/"
```

### 2.3. Первый запуск и разрешения (здесь нужен пользователь)

```bash
open -a /Applications/Handy.app
```

Скажи пользователю дословно, что сейчас произойдёт и что нажать:

1. Откроется окно Handy. Оно попросит доступ к **микрофону**: нажать «Разрешить».
2. Попросит **Универсальный доступ** (Accessibility): откроются системные настройки, там включить
   переключатель напротив Handy. Это нужно, чтобы Handy мог вставить текст туда, где курсор.
3. Если спросит про модель: выбрать **GigaAM v3 E2E-RNN-T** (она уже скачана, ждать не придётся).
4. Написать тебе «готово».

Эти разрешения выдаёт только сам человек, так устроена macOS. Не пытайся обойти. Если окно
настроек не открылось само, открой его:

```bash
open "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility"
```

### 2.4. Настройки

Спроси пользователя одним вопросом, какую клавишу удобно зажимать для диктовки. Предложи `fn`
(левый нижний угол клавиатуры, так стоит у Альберта: зажал, сказал, отпустил). Если `fn` у него
занят переключением языка и это мешает, оставь стандартную `option+space`.

Потом закрой Handy (обязательно: работающий Handy перезапишет файл настроек своим) и примени настройки:

```bash
osascript -e 'quit app "Handy"'; sleep 3; pgrep -x handy && pkill -x handy
curl -fsSL -o ~/.neovida-transcribe/handy_settings.py https://materials.neovida.ai/ai-tseh/potok-4/transcribe/handy_settings.py
~/.neovida-transcribe/venv/bin/python ~/.neovida-transcribe/handy_settings.py --key fn
open -a /Applications/Handy.app
```

Скрипт сам делает копию прежних настроек и меняет только то, что есть в файле: модель GigaAM v3
RNN-T, язык распознавания и интерфейса русский, режим «зажал и говоришь», надёжная вставка (без неё
на загруженном компьютере вместо надиктованного иногда вставляется старое содержимое буфера).
Если скрипт написал «НЕТ ТАКИХ КЛЮЧЕЙ», ничего не выдумывай: перечисли эти пункты пользователю
и покажи, где они включаются в окне настроек Handy. Если написал «НЕТ ФАЙЛА НАСТРОЕК», значит,
первый запуск (2.3) не дошёл до конца: вернись к нему.

### 2.5. Проверка голосом

Попроси пользователя: поставить курсор в любое поле ввода (хоть в твой чат), зажать выбранную
клавишу, сказать «Проверка диктовки, раз, два, три. Запятые и точки ставятся сами», отпустить.
Текст должен появиться там, где курсор, со знаками препинания.

Сам проверь, что распознала именно GigaAM и что вставка сработала:

```bash
grep -o '"selected_model": *"[^"]*"' "$HOME/Library/Application Support/com.pais.handy/settings_store.json"
sqlite3 "$HOME/Library/Application Support/com.pais.handy/history.db" "select transcription_text from transcription_history order by id desc limit 1;"
tail -30 ~/Library/Logs/com.pais.handy/handy.log
```

Успех: в настройках `handy-computer/gigaam-v3-e2e-rnnt-gguf/gigaam-v3-e2e-rnnt-Q8_0.gguf`, в истории
та фраза, которую сказал пользователь, а в логе есть строки
`Successfully loaded transcription model: handy-computer/gigaam-v3-e2e-rnnt-gguf/gigaam-v3-e2e-rnnt-Q8_0.gguf`
и `[reliable-paste] restored previous clipboard`. Сам текст в логе скрыт (`[REDACTED]`), он есть
только в истории. Самая первая диктовка после установки стартует на несколько секунд дольше:
Handy один раз готовит графический ускоритель, дальше модель грузится меньше чем за секунду.

Если что-то не так:

- **Клавиша не срабатывает.** Смотри лог: есть ли строка о регистрации клавиши и события нажатия.
  Чаще всего не выдан «Универсальный доступ» (вернись к 2.3) или Handy не запущен.
- **Текст распознан (есть в истории), но не вставился.** Не выдан «Универсальный доступ».
- **После `fn` переключается язык или вылезают эмодзи.** Системные настройки, «Клавиатура»,
  пункт «Нажатие клавиши 🌐»: предложи пользователю поставить «Ничего не делать» или смени
  клавишу в Handy на `option+space` (скрипт из 2.4 с `--key option+space`, Handy перед этим закрыть).
- **В настройках выбрана другая модель или пусто.** Закрой Handy, проверь, что файл модели лежит
  в папке `models`, запусти скрипт из 2.4 ещё раз, открой Handy.

Если в папке моделей Handy остались старые модели Whisper (файлы `ggml-*.bin`, `whisper-*.bin`),
назови их и размер и спроси, удалить ли. Без «да» не удаляй.

## Шаг 3. Замена Whisper под капотом

По списку из шага 0 пройди каждое место, где Whisper стоит по умолчанию для русской речи.

1. **Твои правила и скиллы** (`~/.codex/AGENTS.md`, `AGENTS.md` в рабочих папках, скиллы, роли):
   сделай копию файла, замени указание «расшифровывай через Whisper» на правило про
   `neovida-transcribe` из инструкции части 1. Одно правило на файл, без дублей.
2. **Скрипты и задачи по расписанию**, которые вызывают Whisper. Если вызов простой («файл на вход,
   текст на выход»), замени на `~/.local/bin/neovida-transcribe "<файл>" -f txt -o "<куда сохранить>.txt" --quiet`
   (текст кладётся в файл, путь к нему печатается последней строкой), прогони скрипт на коротком
   файле и сравни результат. Если вызов сложнее (перевод на другой язык, пословные
   таймкоды для субтитров-караоке, нерусская речь), не трогай: покажи пользователю и спроси.
   GigaAM v3 распознаёт только русский, для других языков Whisper остаётся.
3. **Программы и модели Whisper на диске.** Ничего не удаляй сам. Покажи список с размерами и
   спроси: «Удалить и освободить N ГБ или оставить про запас?»
4. **Другие приложения для диктовки** (если нашлись на шаге 0): не удаляй и не отключай сам.
   Скажи, что теперь диктовка идёт через Handy, и спроси, выключить ли старое, чтобы две программы
   не слушали одну клавишу.

После замены проверь себя: в новом чате фраза «расшифруй вот этот файл» должна привести тебя
к `neovida-transcribe`, а не к Whisper.
