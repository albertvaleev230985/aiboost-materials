Шаг 1. Подключись к серверу и сделай вход по ключу

Мне нужно, чтобы ты работал с моим сервером. Данные из письма хостинга:
адрес [IP сервера, например 185.12.34.56], пользователь root, пароль [пароль из письма хостинга].

1. Проверь, есть ли у меня на компьютере ключ SSH. Нет: создай новый, без парольной фразы.
2. Положи мой открытый ключ на сервер, чтобы дальше входить без пароля. Если ввести пароль в терминал сам ты не можешь, найди безопасный способ (например, через Python и библиотеку paramiko). Пароль нигде не сохраняй.
3. Пропиши сервер в мой файл ~/.ssh/config под коротким именем hermes-server.
4. Проверь: команда ssh hermes-server "hostname && whoami" проходит без пароля.

Дальше в этом чате на сервер заходи только так: ssh hermes-server.
В конце покажи вывод проверки и одной строкой, где у меня лежит ключ.
