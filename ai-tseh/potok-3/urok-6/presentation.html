Промпт 1 · Подключись к серверу и сделай вход по ключу

Мне нужно, чтобы ты работал с моим сервером. Данные из письма хостинга:
адрес [IP сервера, например 185.12.34.56], пользователь root, пароль [пароль из письма хостинга].

1. Проверь, есть ли у меня ключ ~/.ssh/id_ed25519. Нет: создай без парольной фразы. Есть, но с парольной фразой: создай отдельный без неё.
2. Положи мой открытый ключ на сервер. При первом входе прими ключ сервера без вопроса (StrictHostKeyChecking=accept-new). Ввести пароль сам не можешь: попробуй через Python и paramiko во временном окружении. Не вышло за 5 минут: дай мне одну готовую команду для моего терминала (Mac: Терминал, Windows: PowerShell), я вставлю её и сам введу пароль. Пароль нигде не сохраняй.
3. Допиши сервер в ~/.ssh/config, ничего в нём не стирая: Host hermes-server и IP сервера, пользователь root, мой ключ, ServerAliveInterval 30.
4. Проверь: ssh hermes-server "hostname && whoami" проходит без пароля.

Дальше в этом чате на сервер заходи только так: ssh hermes-server.
В конце покажи вывод проверки и одной строкой, где у меня лежит ключ.

Промпт 3 · Что открыто, что закрыто · тот же чат

Проверь с моего сервера (ssh hermes-server) по очереди доступность адресов:
api.telegram.org, hermes-agent.nousresearch.com, chatgpt.com, auth.openai.com, api.openai.com, api.anthropic.com, openrouter.ai, opencode.ai, github.com, pypi.org.
По каждому одна строка: адрес и код ответа. На каждый адрес жди не больше 10 секунд. Код 000 значит, что соединения не было вовсе.

Потом закрытые адреса проверь ещё раз через мой прокси со схемой socks5h. Данные прокси из кабинета proxy6: [адрес, порт, логин и пароль прокси, как они там написаны].
Если прокси не отвечает по socks5h, проверь его как http. Ответил только как http: скажи мне, что в кабинете proxy6 у прокси стоит тип HTTPS и его надо переключить на SOCKS5.
Прокси, который ответил, сохрани на сервере в файл /root/proxy.txt одной строкой socks5h://логин:пароль@адрес:порт и закрой от чужих (chmod 600). Дальше все шаги берут прокси оттуда.
Сервер в США (RackNerd), прокси нет: все шаги про прокси пропусти.

В конце два списка: открыто напрямую и открывается только через прокси. Ничего не устанавливай и не меняй.

Прокси: одна буква решает

socks5h, а не socks5

С буквой h адрес ищет сам прокси, и путь открыт. Без неё сервер ищет адрес Телеграма сам и упирается в IPv6, куда маршрута нет.

Тип SOCKS5 в proxy6

У прокси в кабинете есть тип: HTTPS или SOCKS5. Для Телеграма нужен SOCKS5.

Только IPv4 в одни руки

IPv6 не достучится до ChatGPT, Shared делят три человека. Проверено на втором потоке.

Строку прокси в чат группы не присылаем: по ней в интернет ходит кто угодно за ваш счёт.

Промпт 4 · Поставь Гермеса · тот же чат

Поставь Гермеса на мой сервер (ssh hermes-server). Официальный проект NousResearch/hermes-agent, установщик https://hermes-agent.nousresearch.com/install.sh. Сторонний «Hermes One» не бери.

1. Скачай установщик в файл install.sh через мой прокси из /root/proxy.txt.
2. Устанавливай уже без прокси: GitHub, PyPI и Node.js открыты напрямую, через прокси установка встаёт намертво.
