### Live-сессия

- Облачное состояние: Firebase Realtime Database.
- Корень данных: `ai-tseh-final-2026-07-18`.
- Участникам отправляется только ссылка на экран участника.
- Панель ведущего управляет общей фазой, вопросами, картами и выдачей сертификатов.

### Проверка релиза

Полный сценарий проверен в независимых браузерных контекстах: регистрация → вопрос → ответ → разбор → карта из трёх полей → сертификат → завершение → сброс. Дополнительно проверены восстановление после обрыва сети, межвкладочная синхронизация, порядок отложенных операций, устаревшие ответы Firebase и сброс при открытом офлайн-экране участника.
