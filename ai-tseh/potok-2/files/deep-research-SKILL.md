# Дипресёрч

Скилл делает две вещи: **ставит себе инструменты** и **проводит исследование**.

Определи, что нужно пользователю, по первой фразе:

- «поставь», «установи», «настрой», «подключи», «не работает», «проверь инструменты» → **Режим 1: Установка**
- всё остальное → **Режим 2: Исследование**

---

# Режим 1: Установка

Ты ставишь пользователю 12 инструментов. Половина работает сразу, половине нужен бесплатный ключ.

## Правила разговора при установке

Человек напротив может вообще не понимать, что такое MCP. Веди его за руку.

- Говори по-русски, коротко, без технических терминов там, где можно без них.
- Спрашивай ключи **строго по одному**. Не вываливай список из шести сайтов.
- Перед каждым ключом объясни одной фразой, что даёт этот сервис, и дай прямую ссылку.
- Ключ никуда не пересылай, не выводи в чат целиком и не пиши в файлы проекта. Он уходит только в конфиг Codex.
- Если человек говорит «пропусти» или «потом», спокойно пропускай и иди дальше. Набор работает и частично.
- После каждого шага показывай прогресс: «готово 4 из 12».

## Шаг 0. Проверка

Выполни:

```
codex --version
node --version
```

Нужен Codex 0.140 или новее и Node 18 или новее. Если Node нет, отправь человека на nodejs.org и дождись установки.

Если в системе уже стоят какие-то из этих серверов, не ломай их. Команда `codex mcp add` с тем же именем перезапишет запись, это нормально и безопасно.

## Шаг 1. Шесть инструментов без регистрации

Выполни сразу, ничего не спрашивая. Это даёт человеку рабочий результат в первые две минуты.

```
codex mcp add parallel-search --url https://search.parallel.ai/mcp
codex mcp add you-search-free --url "https://api.you.com/mcp?profile=free"
codex mcp add anysearch --url https://api.anysearch.com/mcp
codex mcp add rivalsearch --url https://RivalSearchMCP.fastmcp.app/mcp
codex mcp add open-websearch --env MODE=stdio --env DEFAULT_SEARCH_ENGINE=duckduckgo -- npx -y open-websearch@latest
codex mcp add playwright -- npx -y @playwright/mcp@latest
```

Скажи: «Шесть инструментов уже стоят, регистрация не нужна. Осталось шесть с бесплатными ключами.»

## Шаг 2. Шесть ключей, по одному

Иди строго по порядку. Первые три самые важные, дальше по убыванию.

### 2.1 Tavily — поиск, который сразу даёт ссылки на источники

Ссылка: https://app.tavily.com
Бесплатно: 1000 запросов в месяц, карта не нужна.

```
codex mcp add tavily --env TAVILY_API_KEY=КЛЮЧ -- npx -y tavily-mcp
```

### 2.2 Firecrawl — превращает любой сайт в чистый текст

Ссылка: https://www.firecrawl.dev/app/api-keys
Бесплатно: 1000 страниц в месяц, карта не нужна.

```
codex mcp add firecrawl --env FIRECRAWL_API_KEY=КЛЮЧ -- npx -y firecrawl-mcp
```

### 2.3 Exa — поиск по смыслу, а не по словам

Ссылка: https://dashboard.exa.ai/api-keys
Бесплатно: 20 долларов на старте плюс 10 долларов каждый месяц.

```
codex mcp add exa --env EXA_API_KEY=КЛЮЧ -- npx -y exa-mcp-server
```

### 2.4 Apify — соцсети, карты, маркетплейсы, отзывы

Ссылка: https://console.apify.com/settings/integrations
Бесплатно: 5 долларов платформы в месяц, карта не нужна.

```
codex mcp add apify --env APIFY_TOKEN=КЛЮЧ -- npx -y @apify/actors-mcp-server --tools docs,actors,apify/rag-web-browser --ui false
```

### 2.5 Jina — читает PDF, снимает скриншоты, ищет в науке

Ссылка: https://jina.ai/api-dashboard
Бесплатно: 10 млн токенов на ключ, карта не нужна.

```
codex mcp add jina -- npx -y mcp-remote https://mcp.jina.ai/v1 --header "Authorization: Bearer КЛЮЧ"
```

### 2.6 Bright Data — берёт то, что закрыто от обычного парсера

Ссылка: https://brightdata.com/ai/mcp-server
Бесплатно: 5000 запросов в месяц первые три месяца, дальше попросит карту.

Предупреди человека про три месяца честно, до регистрации. Если он не хочет, пропусти, набор работает и без этого.

```
codex mcp add brightdata --env API_TOKEN=КЛЮЧ --env GROUPS=ecommerce,social,browser,finance,business,research,app_stores,travel,advanced_scraping,geo,code -- npx -y @brightdata/mcp
```

## Шаг 3. Проверка

```
codex mcp list
```

Покажи человеку итог живыми словами: сколько серверов подключено, какие пропущены и что из-за этого он временно не сможет.

Ориентир, сколько инструментов даёт каждый (проверено 07.08.2026): Bright Data 74, Firecrawl 27, Playwright 24, Jina 21, Apify 10, rivalsearch 9, parallel-search 6, open-websearch 6, Tavily 5, anysearch 4, Exa 2, you-search-free 1. Полный набор это 189 инструментов, только бесключевая часть это 50.

Скажи прямо: **чтобы инструменты заработали, надо выйти из Codex и зайти заново.** Серверы поднимаются при старте.

После перезапуска предложи первый запрос, например: «найди пять свежих обзоров на такой-то товар и скажи, на что жалуются чаще всего».

## Если что-то не встало

- `codex mcp list` показывает сервер, но инструментов нет → перезапусти Codex.
- Ошибка про npx → нет Node, ставь Node.
- Сервер не отвечает и человек в России → почти всегда VPN. Скажи прямо, не гадай.
- Неверный ключ → удали и добавь заново: `codex mcp remove имя`, потом команда добавления снова.
- Ключ вставили с пробелом или переносом строки → частая причина отказа, попроси скопировать заново.

# Режим 2: Исследование

## Главное правило

Дипресёрч это не «нашёл первую ссылку и пересказал». Это **закрыть все разумные источники, прежде чем делать вывод**.

Никогда не пиши «больше ничего нет» после одного поиска. Пиши честно: «проверил такие-то источники, дальше следов не нашёл», и перечисляй, что именно проверял.

Не отвечай по памяти там, где факт можно проверить. Цены, даты, условия, состав, контакты, законы, версии продуктов меняются, а память устаревает.

## Какой инструмент под какую задачу

| Задача | Чем брать |
|---|---|
| Быстрый ответ со ссылками | Tavily |
| «Не знаю, как это называется» | Exa, поиск по смыслу |
| Прочитать конкретную страницу целиком | Firecrawl |
| Обойти весь сайт и собрать структуру | Firecrawl map и crawl |
| Instagram, Facebook, TikTok, YouTube | Apify |
| Google Maps, отзывы, маркетплейсы, Авито | Apify |
| Сайт блокирует парсер, отдаёт капчу | Bright Data |
| Выдача поисковика целиком | Bright Data |
| PDF, научные статьи, arXiv | Jina |
| Скриншот страницы | Jina |
| Зайти под своим логином, покликать | Playwright |
| Перепроверить чужой результат | parallel-search, you-search-free, anysearch, open-websearch |
| Соцсети и форумы широким неводом | rivalsearch |

## Протокол глубины

1. **Пойми задачу.** Кто спрашивает, зачем, какая глубина, к какому сроку, какая география и язык. Если всё ясно, не переспрашивай, начинай.

2. **Собери карту запросов.** Русские и английские варианты, синонимы, точные фразы, названия компаний и продуктов, имена людей, годы, а также профессиональный сленг, которым эту тему называют внутри отрасли.

3. **Иди минимум тремя независимыми маршрутами.** Один поисковик это не исследование. Разные сервисы видят разное.

4. **Спускайся вглубь.** Нашёл нужную страницу, читай её целиком через Firecrawl или Jina, а не по сниппету из выдачи. Сниппет врёт чаще, чем кажется.

5. **Иди в те источники, где живут люди.** Отзывы, комментарии, форумы, реддит, ютуб, телеграм-каналы. Официальный сайт расскажет, как задумано, а люди расскажут, как получилось.

6. **Проверяй ключевые факты по двум независимым источникам.** Особенно цифры, цены и даты.

7. **Разделяй в голове и в ответе:** факт, обещание продавца, чей-то отзыв, твоя догадка. Это четыре разные вещи.

8. **Назови слепые зоны.** Куда не смог зайти, что закрыто логином, где данные старые. Это не слабость ответа, это его честность.

## Как отвечать

Сначала вывод, потом доказательства. Не наоборот, человеку не нужен пересказ твоего пути.

Структура:

1. Ответ в двух-трёх предложениях
2. Разбор по пунктам, с ссылками на источники
3. Что осталось непроверенным и почему
4. Насколько ты сам уверен
5. Один конкретный следующий шаг

Пиши по-русски, плотно, без воды. Если данные слабые, скажи это прямо. Если источник старый, назови дату.

## Границы

Не лезь туда, куда пускают только по логину, если тебе не дали доступ. Не выдумывай данные вместо того, чтобы сказать «не смог зайти». Не обходи защиту сайтов. Если для источника нужен аккаунт или ключ, попроси у человека.

Личные и рабочие данные не отправляй в бесплатные анонимные сервисы (anysearch, open-websearch, rivalsearch). Они хостятся чужими людьми. Для чувствительного бери Tavily, Firecrawl, Exa.

## Примеры запросов, которые скилл закрывает

1. Найди всех конкурентов по услуге в моём городе, с ценами и телефонами
2. Собери отзывы на конкретный товар с трёх маркетплейсов и выдели повторяющиеся жалобы
3. Разбери, что пишут про эту компанию в отзывах сотрудников
4. Найди контакты закупщиков в отрасли и что они публично говорили за последний год
5. Проверь, действительно ли этот подрядчик делал проекты, которыми хвастается
6. Собери посты и комментарии из инстаграма конкурента за три месяца, найди, на что реагируют лучше
7. Найди все ролики на ютубе по теме и вытащи, какие вопросы задают в комментариях
8. Сравни четыре сервиса по реальным условиям, а не по обещаниям с лендинга
9. Найди свежие изменения в законе по моей теме и дату вступления в силу
10. Собери список компаний в отрасли по Google Maps с рейтингом и числом отзывов
11. Проверь, правда ли то, что мне написали в коммерческом предложении
12. Найди, кто уже делал то, что я задумал, и чем у них закончилось
