Оценка звонков
Скоринг 0-100, рекомендации AI после звонка
Включён
N
У команды средняя оценка 74, минимальная — 52. Рекомендую порог красной зоны 50 — отсечёт только провальные звонки. Если поставите 60, будете получать 3-4 алерта в день.
Порог красной зоны ?Звонки с оценкой ниже этого числа считаются проблемными. Они выделяются красным в журнале, РОП получает алерт. Стандартное значение — 50.
Звонки ниже этого значения помечаются как проблемные
Вес «Работа с возражениями» ?Вес определяет насколько сильно этот критерий влияет на итоговую оценку. x1 = стандарт, x2 = вдвое важнее, x3 = втрое. Если клиенты часто торгуются — ставьте x2 или x3, чтобы этот навык был в приоритете.
Увеличьте если это критично для вашей ниши
Анализ речи
Слова-паразиты, темп речи, длинные паузы
Включён
N
У ваших менеджеров в среднем 11 паразитов на звонок. Рекомендую начать с порога 8 — не демотивируйте сразу. Через месяц снизьте до 5.
Порог слов-паразитов (норма) ?Если менеджер использует больше этого числа паразитов за звонок — блок «Речь» в досье подсвечивается как проблема. Средний показатель для B2B продаж: 3-5. Для новой команды начните с 8, потом снижайте.
Выше этого значения — подсвечивается как проблема
Норма темпа речи (слов/мин) ?Скорость речи менеджера. Ниже 120 — слишком медленно, клиент скучает. Выше 150 — слишком быстро, клиент не успевает. Для технических продуктов допустимо 110-140.

Публичный рейтинг ?Менеджеры видят свои позиции относительно коллег. Стимулирует конкуренцию. Но если один менеджер сильно отстаёт — может демотивировать. Тогда лучше оставить только личный прогресс.
