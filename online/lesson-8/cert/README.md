# Как выгрузить сертификаты после урока

## Быстрый способ (для каждого участника)

1. Открой host-окно: `host.html?key=albert2026` → скопируй имена участников из карточек
2. Для каждого открой:
   ```
   https://materials.neovida.ai/online/lesson-8/cert/?name=Имя+Фамилия
   ```
   (пробел в URL = `+` или `%20`)
3. Нажми **Cmd+P** → **Save as PDF** → ландшафтная ориентация
4. Сохрани файл как `Сертификат_Имя_Фамилия.pdf`
5. Отправь в личку TG вместе с шаблоном из `tg-сообщения/после-урока-персональное.md`

## Пример URL
```
https://materials.neovida.ai/online/lesson-8/cert/?name=Иван+Иванов
https://materials.neovida.ai/online/lesson-8/cert/?name=Иван%20Иванов
```

Обе формы работают одинаково.

## Локальная проверка перед уроком
Открой файл `template.html` напрямую в браузере, введи тестовое имя в поле сверху → распечатай. Если всё ок — зальётся идентично на проде.

## Если имя длинное (3+ слова)

Шрифт автоматически уменьшается по длине строки (40pt для 22+ символов, 46pt для 18-22, 54pt по умолчанию). Если все равно выходит за границы — сократи в URL: «А. Иванов» или «Иван И.».

## Серийный номер

Генерится из хеша имени, формат: `NV · AIB · 2026 · ONLINE-1 · XXXXX`. У каждого участника — уникальный, повторно открыв ту же ссылку получишь тот же серийник.

## Если хочешь сменить дату
Добавь `?date=12.05.2026` в URL (по умолчанию — `11 мая 2026`).
