# Сертификаты онлайн-курса · Поток 1

11 выпускников. Альберт Валеев — ведущий, без сертификата.

## URL

https://materials.neovida.ai/online/lesson-8/certificate/

## Как пользоваться

1. Открой URL в Chrome
2. В правом верхнем углу — селектор имени. Выбери участника
3. Нажми **«📥 Скачать PDF»** (или Cmd+P → Save as PDF → A4 Landscape)
4. Сохрани как `01-Бондаренко-Иван.pdf`, `02-Колган-Михаил.pdf` и т.д.
5. Повтори для всех 11
6. Отправь в личку каждому по шаблону из `tg-сообщения/после-урока-персональное.md`

## Что нужно от Альберта

Жду от тебя 2 файла (PNG с прозрачным фоном):
- **`signature.png`** — твоя роспись. Размер ~600×280px, должна выглядеть как обычная подпись чернилами. Если есть только скан на белом фоне — могу сам удалить фон (просто пришли как есть)
- **`stamp.png`** — печать. Квадратная, ~600×600px, прозрачный фон вокруг круга

Как только пришлёшь — я положу их в `сертификаты/signature.png` и `сертификаты/stamp.png`, и они автоматически появятся на ВСЕХ 11 сертификатах в нужных местах.

**Расположение на сертификате:**
- Подпись: над линией «Альберт Валеев · основатель neovida.ai» в левой нижней части
- Печать: в центральном круге «место печати» (40×40 мм)

Если файла нет — отображается дефолт (линия + текст «место печати»). Сертификат всё равно валидный, просто без атрибутов.
