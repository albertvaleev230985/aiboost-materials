Один понятный маршрут

Персонализацию вы уже прошли. Сегодня: поставить задачу, улучшить ответ, сохранить способ работы.

  1. Выберите любую свою задачу, например из десяти, предложенных ИИ после персонализации. Самостоятельно составьте запрос по РКЗФО: роль, контекст, задача, формат, ограничения. Запустите и оцените ответ.
  2. После первого запуска посмотрите готовые заводские промпты ниже. Можно оставить свою задачу или взять подходящую из библиотеки. Замените вводные своими, уточните результат и запустите итоговый запрос. С этой задачей проходите дальнейшую цепочку в одном чате.
  3. Уточняющие вопросы перед выполнением.
  4. В том же чате: совет → недостающая роль → разбор по фактам → проверка чисел → чистовик.
  5. Шестой ход: три версии под адресатов.
  6. Обратный промптинг: образец → готовый промпт → проверка в новом чате.
  7. Сохранённая инструкция → повторный запуск → преднастроенный ассистент.

Для первого ассистента достаточно инструкции и входных данных. Документы базы знаний можно добавить позже, когда станет понятно, каких сведений не хватает.

I · Промпт-инженерия

Промпт: инструкция ИИ, в которой вы объясняете задачу, исходные данные и нужный результат. Одна задача на запрос; понятный контекст; конкретный формат; вопросы при нехватке данных; проверка по фактам; точная правка вместо «сделай лучше».

Приёмы 1–12

1. РКЗФО · 2. Вопросы первым · 3. Совет экспертов · 4. Три адресата · 5. Обратный промптинг · 6. По шагам · 7. Этапы · 8. Итерации · 9. Формат · 10. Попроси правду · 11. Образец · 12. Наговори голосом.

Наговори голосом: как сделать

  1. Нажмите микрофон ввода или включите диктовку клавиатуры. Расскажите, что случилось, что уже известно и что хотите получить.
  2. Проверьте распознанный текст: имена, числа и технические обозначения.
  3. Попросите ИИ задать вопросы и собрать промпт по РКЗФО. Полная формулировка.
  4. Ответьте на вопросы, прочитайте собранный промпт, исправьте и попросите выполнить.

II · Ассистентный подход

Ассистент: помощник с сохранённой инструкцией для повторяемой задачи. Один понятный пакет входных данных → одна функция → один проверяемый результат. «Один вход» может содержать несколько файлов.

Сначала сохраните удачный способ работы. Не нужна заранее собранная база знаний: для первой версии достаточно инструкции и данных текущей задачи.

  1. Распакуйте процесс: событие, вход, действия, результат, проверка.
  2. Согласуйте схему и действия при неполных данных.
  3. Соберите инструкцию одним блоком.
  4. Проверьте критиком и исправьте.
  5. Сохраните инструкцию в выбранном инструменте.
  6. Пройдите три теста. После правки повторите их.

Можно адаптировать готового для работы, команды или жизни, либо описать собственный процесс и пройти те же шаги. Документы добавляются позже: какие знания нужны помощнику.

Одна инструкция · два инструмента

Начинаем с привычного ChatGPT. Затем используем ту же инструкцию в Gemini. Роль, порядок работы и три теста остаются одинаковыми.

ChatGPT · проект

  1. Создай новый проект под одну повторяющуюся задачу.
  2. Открой меню проекта → настройки проекта → добавь инструкцию ассистента.
  3. Начни новый чат внутри проекта и дай исходные данные задачи.
  4. Проверь обычный, неполный и противоречивый запрос.

Инструкции проекта действуют внутри него. Проект объединяет чаты, файлы и правила работы; это не отдельный GPT.

ChatGPT · GPT

Если редактор доступен: GPTs → Create → название → Instructions → пробный запрос в Preview → сохранение. Для существующего GPT можно открыть редактирование.

По текущей справке OpenAI создание новых GPT на личных аккаунтах, включая платные, недоступно. В рабочих пространствах доступ зависит от плана и разрешений. Ведущий показывает доступный редактор; для практики участников остаётся проект с инструкцией.

Gemini · Gem

  1. Открой веб-версию Gemini → Gems → новый Gem.
  2. Дай понятное название и вставь ту же инструкцию.
  3. Выполни пробный запрос, затем нажми Save.
  4. Открой сохранённого помощника и проверь три сценария.

Если настройка недоступна, сохрани инструкцию текстом и запусти её в новом обычном чате.

Три теста

Обычный запрос: правильный результат. Неполный: вопросы вместо выдумок. Противоречивый: конфликт обнаружен, актуальная версия уточнена. После правки инструкции повтори все три.

Блокнот собирает выбранные материалы и помогает задавать вопросы по ним, сравнивать сведения и проверять основания ответа. В некоторых интерфейсах и справке используется название Gemini Notebook.

Подключение к личному Gem

  1. Откройте редактирование своего Gem.
  2. В разделе Knowledge / Знания выберите Add files → More uploads → Notebooks.
  3. Выберите доступный блокнот и сохраните Gem.

Если пункта Notebooks нет, добавьте те же учебные файлы непосредственно в Knowledge. Это подключение файлов, а не самого блокнота. Блокноты NotebookLM не поддерживаются как источники для общих Gems; для команды можно передать инструкцию и использовать обычные файлы.

Полная инструкция

Собери совет из четверых, у каждого свой взгляд:

- Прямолинейный скептик: его единственная задача найти дыры в этом решении
- Профильный специалист: подбери его сам под мою задачу и назови, кого выбрал

Пусть каждый выскажется по очереди, своим голосом, начиная реплику со своей роли. Им разрешено спорить друг с другом и возражать по именам ролей. Согласие из вежливости запрещено.
Когда выскажутся все, дай короткое резюме: в чём сходятся, в чём расходятся, и один вопрос, на который мне нужно ответить прежде, чем решать.
