Шаг 3. Подключи Desktop к серверу

Открой Settings → Gateways («Настройки → Подключения»).

  • Сервер уже в списке? Выбери его и нажми Test.
  • Нового подключения ещё нет? Add connection → SSH. Скопируй проверенный SSH host и путь к Hermes из карточки Codex. Сохрани и нажми Test.
  • Reachable означает «сервер доступен». This device или Local обозначает сам ноутбук.

Шаг 5. Сверь модель в двух окнах

Смотри на настройку в каждом окне. Один и тот же профиль допускает разные модели в разных разговорах.

  • Telegram: отправь /model без аргументов. Посмотри текущий выбор. Если он неясен — /status или сведения сеанса.
  • Desktop: у поля сообщения открой выбор модели этого разговора.
  • Settings → Model → Main model показывает основную модель профиля. Если есть Applies to, проверь, к какому профилю относится экран.

Справка о себе

Зачем этот промпт: чтобы Кириллу не приходилось заново представляться в каждом разговоре.

  • Codex соберёт короткую справку в obo-mne.md — текстовом файле «обо мне».
  • Кирилл проверяет факты. Гермес читает справку, чтобы учитывать их в своих ответах.
  • В новом разговоре спроси: «Что ты обо мне знаешь и откуда?» Сверь ответ с файлом.

Поручение по расписанию

Зачем этот промпт: выбрать одно дело, результат которого Кирилл хочет получать без повторной просьбы.

  • Кейсбук — подборка примеров. По нему агент предложит три дела, а Кирилл выберет одно.
  • Поручение описывает задачу, расписание задаёт время повторения.
  • Запустите дело сразу. Откройте результат в Telegram и проверьте время следующего запуска.

Перенос задачи с GitHub

Зачем этот промпт: перенести на сервер дело, которое уже выполняется в GitHub по расписанию. Если такого дела нет, это пример для разбора.

  • Репозиторий — проект, где хранится код. Скрипт — программа, выполняющая задачу.
  • Агент найдёт расписание, проверит, может ли запустить программу на сервере, и покажет результат.
  • Кирилл проверяет доставку в Telegram. Старое расписание выключают только с его согласия.

Если обмен не заработал

Если папки не обмениваются файлами, занятие можно продолжить через работающего бота.

  • Запасной промпт нужен, чтобы у Гермеса появилась копия правил с ноутбука.
  • Компьютер раз в час отправляет файлы на сервер по SSH — через защищённое соединение.
  • Проверка: спроси бота о правилах и навыках. При таком варианте заметки с сервера обратно на ноутбук не приходят.
