Gem-бот

Один ассистент под один повторяемый процесс: КП, тендер, звонок, документы, SMM или ремонт.

Понимание агентов

Где нужен Manus или Deep Research, а где достаточно обычного Gemini/Gem.

База знаний для Gem и NotebookLM

Gem без материалов — сильный промпт. Gem с материалами — уже рабочий помощник.
Продажи / сервис

FAQ по услугам, шаблоны КП, список вопросов к клиенту, типовые возражения, правила тона.

ТМЦ / тендеры

Чек-лист позиции, критерии совместимости, шаблон запроса поставщику, риски маржи, список полей.

Колл-центр

Скрипты, чек-лист качества звонка, типовые вопросы, правила следующего шага, примеры хороших фраз.

ЭДО / документы

Список документов, статусы, шаблоны писем, сценарии напоминаний, чек-лист комплектности.

SMM

Рубрикатор, тон бренда, примеры постов, описание услуг, вопросы для кейса, форматы площадок.

Ремонт

Типовые причины ремонта, объяснения клиенту, ограничения обещаний, вопросы инженеру, сценарии согласования.

В учебной практике не загружаем ФИО, телефоны, реквизиты, реальные договоры, счета, выгрузки 1С/CRM/ЭДО и персональные данные. Обезличиваем до загрузки.

NotebookLM: создать рабочий блокнот

Один блокнот — одна тема. Иначе ответы становятся шумными.
  1. Откройте notebooklm.google.com.
  2. Создайте новый блокнот: «КП сервис», «Тендеры», «ЭДО», «Звонки», «SMM».
  3. Загрузите 3-5 безопасных источников одной темы.
  4. Задайте 2 проверочных вопроса и посмотрите, ссылается ли NotebookLM на источники.
  5. Сделайте справочник: FAQ, таблицу, briefing document или свой отчёт.
  6. Используйте выводы как Knowledge для Gem или как отдельную рабочую памятку.
По справке Google, NotebookLM поддерживает PDF, Word, Markdown, текст, Google Docs/Slides/Sheets, веб-URL, публичные YouTube URL, изображения и аудио. Источник хранится как статическая копия: если исходный файл изменился, его нужно синхронизировать или загрузить заново.
Промпт: вытащить справочник из NotebookLM
На основе загруженных источников сделай: 1. краткий справочник по этому процессу; 2. список типовых вопросов клиента или сотрудника; 3. таблицу: вопрос → где в источниках ответ → как отвечать; 4. список пробелов: чего в источниках не хватает; 5. материал, который можно вставить в инструкцию Gem. Отдельно отметь, какие ответы можно давать уверенно по источникам, а где нужна проверка человека.
Промпт: проверить качество базы
Проверь мой блокнот как база знаний для рабочего ассистента. Тема блокнота: [тема]. Источники: [перечислите источники]. Задача будущего Gem: [что должен делать]. Оцени: 1. каких источников достаточно; 2. каких источников не хватает; 3. какие источники могут шуметь и сбивать ответы; 4. какие вопросы Gem всё равно должен задавать человеку; 5. какие данные нельзя добавлять без очистки. Дай короткий план доработки базы на 20 минут.

Gemini Canvas: мини-приложение

Делаем не красивую игрушку, а инструмент для повторяемой задачи.
КП-конструктор

Из заявки делает структуру КП, вопросы и письмо клиенту.

Радар тендера

Подсвечивает риски, пробелы, вопросы поставщику и проверки маржи.

Контроль звонка

Даёт оценку разговора, слабые места и следующий шаг.

Чек-лист ЭДО

Проверяет комплект документов и формирует письмо по недостающему.

SMM-планер

Упаковывает сервисный кейс в пост, сценарий и набор заголовков.

Ремонт простым языком

Помогает объяснить клиенту состав работ и ценность ремонта.

Универсальный промпт для Canvas
Создай в Gemini Canvas мини-приложение для PrintMaster. Роль: ты senior frontend-разработчик и продуктовый дизайнер B2B-инструментов. Контекст: PrintMaster обслуживает офисную технику, ремонтирует принтеры, заправляет картриджи, работает с корпоративными клиентами, тендерами, документами и прямыми договорами. Задача: сделать одностраничное приложение «[название]» для [роль/отдел]. Пользователь вводит: [3-7 полей]. Приложение выдаёт: [таблица, чек-лист, письмо, оценка, план]. Требования: - один HTML-файл без сервера; - современный спокойный дизайн, без кислотных цветов; - адаптация под телефон; - кнопка «Сформировать»; - блок «Что проверить человеку»; - не выдумывать цены, сроки, законы и технические характеристики; - если данных мало, показывать список недостающих вводных. Сначала создай рабочую версию, затем предложи 5 улучшений.
Промпт: КП-конструктор
Создай в Gemini Canvas одностраничное мини-приложение «КП-конструктор PrintMaster». Пользователь вводит: 1. тип клиента; 2. что нужно обслужить или отремонтировать; 3. какая проблема или задача; 4. что уже известно; 5. ограничения по срокам; 6. что нельзя обещать без проверки. Приложение выдаёт: 1. краткую сводку заявки; 2. список уточняющих вопросов; 3. структуру коммерческого предложения; 4. черновик письма клиенту; 5. блок «что проверить человеку». Дизайн: спокойный B2B, чистый светлый фон, графитовый текст, один фиолетовый или бирюзовый акцент, без градиентной попсы.

Manus: агент для многошаговых задач

Агент работает с многошаговыми задачами, но внутренние данные PrintMaster остаются вне публичной задачи.
Manus по партнёрской ссылке
manus.im/invitation/I28CAQTOUMYPRGU
Режимы

Chat Mode — быстро обсудить и получить ответ. Agent Mode — поручить многошаговую работу: исследование, сайт, слайды, файл, таблицу. Agent Mode расходует кредиты.

Безопасная публичная задача для Manus
Собери публичное исследование: как компании по обслуживанию офисной техники в России описывают сервис, ремонт, заправку картриджей и корпоративное обслуживание. Нужно: 1. найти 8-10 публичных сайтов; 2. выделить типовые услуги и офферы; 3. собрать таблицу: компания, услуги, сильные формулировки, что можно улучшить; 4. предложить 10 идей контента для PrintMaster; 5. оформить результат как короткий отчёт и таблицу. Не используй внутренние документы PrintMaster. Работай только с публичными источниками.

Deep Research: когда нужен глубокий поиск

Не для каждого запроса. Сильный режим, когда нужна картина рынка и источники.
Использовать
  • конкуренты и рынок;
  • поставщики и альтернативы;
  • тренды 2025-2026;
  • подготовка к стратегии;
  • сравнение подходов.
Не тратить время
  • обычное письмо;
  • срочный ответ клиенту;
  • внутренний документ с закрытыми данными;
  • простая таблица;
  • то, что уже есть в вашей базе.
Промпт для Deep Research
Роль: B2B-аналитик рынка сервисного обслуживания оргтехники в России. Контекст: PrintMaster работает с корпоративными клиентами, ремонтом принтеров, обслуживанием офисной техники, картриджами, тендерами и документами. Задача: исследуй, как в 2025-2026 годах компании в России продвигают сервис оргтехники для B2B. Найди рабочие формулировки, офферы, услуги, каналы продвижения и слабые места конкурентов. Формат отчёта: 1. карта рынка; 2. таблица 10 публичных примеров; 3. что у них хорошо; 4. где слабые места; 5. 10 идей для PrintMaster; 6. что можно внедрить за 2 недели; 7. ссылки на источники. Ограничения: только публичные источники, даты 2025-2026, не выдумывать цены и факты.

Финальный чек-лист после урока

Минимум, который нужно довести до рабочего состояния.
  1. Gem создан, назван по процессу и сохранён.
  2. В инструкции есть роль, контекст, формат, вопросы при нехватке данных, запреты и проверка человеком.
  3. Gem прошёл три теста: обычный, сложный, неполный.
  4. NotebookLM-блокнот собран по одной теме, не по всему отделу сразу.
  5. Источники очищены от персональных и закрытых данных.
  6. Есть справочник из NotebookLM, который можно использовать в Gem или в работе.
  7. Canvas-приложение создано или есть точный промпт для него.
  8. Manus и Deep Research понятны как отдельные режимы для многошаговых задач и исследований.
Если что-то не получилось на уроке, не чините всё сразу. Сначала доведите один процесс и один Gem. Один работающий инструмент лучше пяти недособранных.
