Сертификат не выдаётся отдельной ссылкой
Правильный сценарий: участник входит по имени и фамилии → проходит тест → заполняет карту → ты нажимаешь «Выдать сертификаты» в host dashboard → у участника появляется поздравление, фейерверк и кнопка «Открыть мой сертификат». Имя в сертификате берётся из формы входа участника.
7 полей карты
Название Gem или ассистента, рабочий процесс, что он делает, какие материалы подключены, статус тестирования.
Gem: Помощник по КП PrintMaster.
Процесс: подготовка черновика КП по входящей заявке.
Что делает: задаёт уточняющие вопросы, собирает структуру КП, готовит черновик письма клиенту.
База знаний: шаблон КП, FAQ по услугам, прайс.
Статус: протестировал(а) на 2 заявках, нужно добавить свежий прайс.
Если Canvas уже есть, участник описывает его. Если нет, фиксирует, какой небольшой инструмент нужен для работы.
Canvas: чек-лист входящей заявки.
Зачем: быстро понять, хватает ли данных для КП.
Что вводим: тип задачи, размеры, материалы, сроки, вводные клиента.
Что получаем: список недостающих данных и готовые вопросы клиенту.
Статус: черновик есть / хочу собрать в июне.
Не “пользуюсь ChatGPT”, а конкретные процессы, которые уже переводятся в ассистента, Gem, NotebookLM или Canvas.
1. Входящие заявки клиентов — через Gem, который уточняет вводные и готовит структуру ответа.
2. Поиск ответов в документах — через NotebookLM с регламентами.
3. Проверка комплектности данных — через Canvas-чек-лист.
1-3 рабочих процесса, которые участник реально начинает делать через ИИ регулярно.
1. Каждую новую заявку прогонять через Gem «Помощник по КП».
2. Раз в неделю обновлять базу знаний свежими прайсами и типовыми ответами.
3. Перед отправкой клиенту проверять письмо через ассистента на полноту и понятность.
Материалы, доступы, база знаний, владелец процесса, решение руководителя, тестовые кейсы, срок пересмотра.
Нужно: свежий прайс, 5 хороших КП, FAQ по типовым вопросам, папка в Drive, ответственный за обновление базы, 3 тестовые заявки для проверки качества.
Главное поле для руководителя. Оно попадает в общий отчёт: процесс, ассистент/Gem, старый способ, новый способ, результат, экономия, что докрутить.
Процесс: подготовка черновика КП.
Ассистент/Gem: «Помощник по КП PrintMaster».
Как раньше: вручную собирал(а) структуру из старых КП и прайса.

Результат: меньше пропущенных вводных, быстрее первый черновик.
