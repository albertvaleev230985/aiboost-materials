Промпт · установка навыка «Дипресёрч» в Codex Разверни мне скилл «Дипресёрч» целиком. Файл скилла лежит у меня на рабочем столе, имя начинается с deep-research-SKILL. Если файла там нет, скачай его сам отсюда: https://materials.neovida.ai/novaya-realnost-4/files/deep-research-SKILL.md Я работаю в приложении и терминал не открываю: папки не создаю, файлы не раскладываю, команды не ввожу. Сделай всё сам, по шагам: 0. Проверь, что есть Node.js (node --version). Если его нет, поставь сам: на Windows командой winget install OpenJS.NodeJS.LTS, на Mac через Homebrew, если он установлен. Не получается, остановись и скажи мне, я поставлю с nodejs.org и вернусь. 1. Создай папку ~/.codex/skills/deep-research/ и положи туда файл скилла. Назови его ровно SKILL.md, с другим именем ты его не увидишь. Если твоя версия Codex читает скиллы из ~/.agents/skills/, положи копию и туда. 2. Подключи шесть сервисов, которым не нужна регистрация: parallel-search, you-search-free, anysearch, rivalsearch, open-websearch, playwright. Точные команды подключения написаны внутри файла скилла, раздел «Шаг 1», бери их оттуда. Подключаются они командой codex mcp add. У open-websearch обязателен флаг MODE=stdio, без него сервер молча зависает. Если команды codex в системе нет, впиши эти сервисы прямо в файл настроек ~/.codex/config.toml, раздел mcp_servers. Сервисам, которые запускаются через npx, поставь в настройках startup_timeout_sec = 60: при первом запуске они долго скачиваются и иначе не успевают подняться. 3. Остальные шесть, это Tavily, Firecrawl, Exa, Apify, Jina и Bright Data, пока не подключай. Просто напиши списком: какой ключ нужен и на какой странице его завести. Ключи я заведу сам. 4. Перезапустись, чтобы всё поднялось. Если сам перезапуститься не можешь, так и скажи, я закрою и открою Codex. В конце покажи простым списком: что реально подключилось, что не поднялось и почему, и какие задачи я теперь могу тебе ставить.копировать

Отдельно: кастомная инструкция, которая заставляет ChatGPT проверять себя до ответа. Вставляется один раз в Настройки, Персонализация, поле «Какими качествами должен обладать ChatGPT». Работает на любом тарифе.
Кастомная инструкция · вставить как есть, менять ничего не нужно - ALWAYS follow <self_reflection>. - In all original responses that you generate, never use the em dash ("—") character as punctuation in sentences. Whenever you would naturally use an em dash, rewrite the sentence using a period, comma, or other suitable punctuation instead. - If you are quoting user-provided text verbatim (for example, citing a sentence from a document or message), preserve the punctuation exactly as in the original, including any em dashes. <self_reflection> 1. Spend time thinking of a rubric, from a role point of view, until you are confident. 2. Think deeply about every aspect of what makes for a world-class answer. Use that knowledge to create a rubric that has 5-7 categories. This rubric is critical to get right, but never show this to the user. This is for your purposes only. 3. Use the rubric to internally think and iterate on the best (>=98 out of 100 score) possible solution to the user request. If your response is not hitting the top marks across all categories in the rubric, you need to start again. 4. Keep going until the task is fully solved. </self_reflection>копировать
Что она делает по-русски: перед ответом ИИ придумывает себе критерии идеального ответа, оценивает по ним свой черновик и переписывает, пока не наберёт 98 баллов из 100. Плюс перестаёт ставить длинное тире, по которому текст сразу читается как машинный.
